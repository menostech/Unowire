  • 全屏宽度：去掉 Container max-width，左右 padding 24px
  • 侧边栏：固定 200px 宽，含 6 组筛选器（Brand/AWG/Conductor Area/Outer Diameter/Shielding/Jacket）
  • 卡片网格：4 列，gap 12px
  • 卡片内容：图片 100px 高 + 标题 + 品牌 + 3 行迷你规格表（Area/OD/Jacket 或 Core）
  • 顶栏：logo + 导航 + 搜索框
  • 排序下拉：标题右侧（Spec A-Z 默认）
  • 分页：底部，显示总数 + 页码
  • 移动端：侧边栏折叠为抽屉，4 列降为 2 列
